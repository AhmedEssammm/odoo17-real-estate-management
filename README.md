# Real Estate Management System | Odoo 17

## 📌 Overview
A custom **Real Estate Management System** built on **Odoo 17** that enables companies to manage properties, units, owners, customers, and sales workflows efficiently.  

This module demonstrates clean Odoo development practices, including models, views, controllers, wizards, reports, and access control.

---

## ✨ Key Features
- **Property & Building Management**: Create, update, and manage real estate properties and buildings  
- **Owner & Client Tracking**: Link properties to owners and track client inquiries  
- **State-Based Workflow**: Manage property states such as Draft, Pending, Sold, or Closed  
- **Wizards**: Implement bulk operations and guided user interactions  
- **Reports**: Generate PDF/Excel reports for properties and sales  
- **Access Rights & Record Rules**: Fine-grained user permissions for sensitive operations  
- **Controllers**: Custom server-side logic for frontend or web interactions  
- **Static Assets**: Includes images and CSS for improved UI  
- **i18n**: Supports translations for multiple languages  
- **Automated Tests**: Ensures module stability and correctness

## 🚀 Installation
1. Copy the module to your Odoo `custom_addons` directory
2. Restart Odoo server
3. Activate Developer Mode
4. Update Apps List
5. Install **Real Estate Management System**
